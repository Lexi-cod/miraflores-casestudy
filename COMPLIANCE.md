# Requirement coverage and operating boundaries

Source: the three-page case-study brief and the supplied packet README. This matrix describes implemented mechanisms, not a certification or a claim that every new workflow has been exercised. The completed manual walkthrough and its remaining limits are documented in MANUAL_VALIDATION.md. UI copy changes do not establish production readiness.

## Filing gates

Freezing requires every form independently reviewed, current verifications, dispositioned findings, no open notes, all documents/areas/required steps concluded, independently reviewed judgments including California AMT, complete outside-filing conclusions, approved adjustments with resolved overlapping tax effects, ordered signatures and both current spouse authorizations. A finding disposition never substitutes for a tie-out. Assigning work never grants extra data permissions.

## Deployment and data handling

The app makes no external AI, analytics or CDN calls. Local mode keeps records on the workstation. Hosted mode uses Render infrastructure and Postgres. The public, role-switchable submission uses only the supplied fictional case; production client data requires authenticated access, firm-approved hosting, consent/disclosure processes where applicable and a managed security/retention program. The case simulation does not establish real-world legal compliance.

The user selected a free 30-day Render database. Export the complete binder before expiry. The seven-year workflow remains available in a persistent local or otherwise appropriately hosted installation; a 30-day provider lifetime does not become seven-year preservation merely because the application records a retention date.
