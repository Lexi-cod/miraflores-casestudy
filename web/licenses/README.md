# Brand typefaces

The portal uses the public visual palette and wordmark treatment of https://miraflores.ai/ as requested by the project owner.

Fraunces (normal, variable weights 300-600, Latin subset) and Poppins (700, Latin subset) are served locally. The font files were obtained from the Google Fonts stylesheet linked by the public Miraflores site. No external font request is made by the portal.

The adjacent OFL files contain the respective font licenses. These fonts are redistributed under the SIL Open Font License 1.1. The Miraflores name and wordmark remain their owner's branding.
